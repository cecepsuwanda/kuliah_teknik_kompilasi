\subsection{Contoh Inferensi}

Untuk program
\begin{lstlisting}[language=C]
int a = 2;
float b = 3.5;
float c = a + b;
\end{lstlisting}
tipe \code{a} adalah \code{int}, tipe \code{b} adalah \code{float},
dan tipe \code{a + b} adalah \code{float}. Assignment ke \code{c}
valid karena \code{float} assignable ke \code{float}. Jika
\code{c} bertipe \code{int}, assignment memerlukan cast eksplisit
yang belum didukung v1.0.

\subsection{Propagasi Error}

Jika sebuah identifier tidak ditemukan, tipe ekspresinya menjadi
\code{error}. Operator yang menerima \code{error} mengembalikan
\code{error} tanpa melaporkan kesalahan baru. Strategi ini mencegah
satu kesalahan awal menghasilkan puluhan pesan turunan.

\begin{warningbox}
Jangan melaporkan kesalahan tipe berulang untuk ekspresi yang sama.
Gunakan nilai \code{error} sebagai peredam dan laporkan hanya
kesalahan akar.
\end{warningbox}
