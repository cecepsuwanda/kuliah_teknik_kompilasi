\section{Penelusuran Fase untuk Program C Sederhana}
\label{sec:ch03-pass}

Hubungan antarfase menjadi lebih jelas bila kita menelusuri satu
program konkret. Alur token, pohon, lalu kode antara mengikuti catatan
pembuka Juarna. Perhatikan program C berikut.

\begin{lstlisting}[language=C]
int main() {
    int a = 5;
    int b = 7;
    print(a + b);
    return 0;
}
\end{lstlisting}

Setiap fase mempertahankan atau memperkaya informasi dari fase
sebelumnya. Analisis leksikal membuang spasi dan komentar, tetapi
menyimpan lokasi. Analisis sintaksis menyusun token menjadi struktur.
Analisis semantik menambahkan tipe dan referensi simbol. Pembangkitan
kode antara mengubah struktur menjadi instruksi sederhana yang siap
diterjemahkan ke kode target.

\subsection{Catatan tentang Lintasan}

Kompilator satu lintasan (\eng{one-pass compiler}) membaca program
sekali dan langsung menghasilkan kode target, sedangkan kompilator
banyak lintasan (\eng{multi-pass compiler}) membaca representasi
antara beberapa kali. Perbedaan ini memengaruhi jumlah lintasan dan
kebutuhan memori, tetapi tidak mengubah keluaran yang harus dicatat
pada tabel penelusuran: token, pohon sintaks, dan kode antara tetap
menjadi bukti utama.

\begin{warningbox}
Jangan mengisi tabel penelusuran dengan istilah umum seperti
``token dihasilkan'' atau ``pohon dibuat''. Setiap sel harus memuat
contoh konkret dari program yang sedang ditelusuri, misalnya nama
token, bentuk pohon, atau instruksi tiga alamat.
\end{warningbox}
