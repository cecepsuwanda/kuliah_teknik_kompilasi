\subsection{Scope Bersarang}

Setiap blok dan fungsi memiliki scope sendiri. Saat parser memasuki
blok, tabel simbol mendorong scope baru. Saat blok selesai, scope
dilepas dan simbol-simbolnya tidak lagi terlihat.

\subsection{Shadowing}

\begin{definisi}[Shadowing]
Shadowing terjadi ketika identifier pada scope dalam memiliki nama
yang sama dengan identifier pada scope luar. Identifier dalam
menutupi identifier luar selama scope dalam aktif.
\end{definisi}

\begin{contoh}[Shadowing]
\begin{lstlisting}[language=C]
int x = 1;
{
    int x = 2;
    print(x);
}
print(x);
\end{lstlisting}
Di dalam blok, \code{x} merujuk ke variabel lokal bernilai 2.
Setelah blok selesai, \code{x} kembali merujuk ke variabel global
bernilai 1.
\end{contoh}

\subsection{Deklarasi Ganda}

Deklarasi ganda dalam scope yang sama merupakan kesalahan. Parser
semantik harus memanggil \code{lookup\_current} sebelum
\code{define}. Jika simbol sudah ada, laporkan kesalahan dan jangan
menambahkan simbol baru.

\begin{infobox}
Shadowing berbeda dari deklarasi ganda. Shadowing melibatkan scope
berbeda; deklarasi ganda melibatkan scope yang sama. Keduanya harus
dibedakan dalam pesan kesalahan.
\end{infobox}
