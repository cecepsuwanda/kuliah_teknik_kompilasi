\subsection{UTS Praktik}

UTS Praktik menekankan penerapan:
\begin{enumerate}[label=\arabic*.,leftmargin=*]
  \item tabel penelusuran fase: token, pohon sintaks, dan kode antara;
  \item klasifikasi lima grammar dan tabel pemetaan Tipe 3--0;
  \item FIRST/FOLLOW dan tabel LL(1);
  \item tabel SLR/LALR serta debug konflik;
  \item pengujian parser pada string valid dan tidak valid.
\end{enumerate}

\subsection{UAS Tulis}

UAS Tulis menekankan konsep dan analisis:
\begin{enumerate}[label=\arabic*.,leftmargin=*]
  \item arsitektur kompilator dan hubungan antarfase;
  \item analisis semantik dan type checking;
  \item validasi AST dan diagnostik;
  \item studi kasus program dengan kesalahan;
  \item refleksi dan desain solusi.
\end{enumerate}

\subsection{Proyek Akhir}

Proyek akhir menilai kemampuan integrasi:
\begin{itemize}[leftmargin=*]
  \item pipeline lexer--parser--AST--type checker--validator;
  \item kualitas kode dan pengujian;
  \item dokumentasi dan demo;
  \item kemampuan menjelaskan keputusan desain.
\end{itemize}

\subsection{Contoh Soal UTS Praktik}

\begin{enumerate}[label=\arabic*.,leftmargin=*]
  \item Diberikan program C, lengkapi tabel penelusuran fase: token,
        pohon sintaks, dan kode antara.
  \item Diberikan lima grammar, klasifikasikan dan isi tabel pemetaan
        Tipe 3--0.
  \item Hitung FIRST/FOLLOW dan bangun tabel LL(1).
  \item Bangun tabel SLR/LALR dan tandai konflik yang muncul.
  \item Uji parser pada string valid dan tidak valid, lalu tulis pesan
        kesalahan yang informatif.
\end{enumerate}

\subsection{Contoh Soal UAS Tulis}

\begin{enumerate}[label=\arabic*.,leftmargin=*]
  \item Diberikan program C, lengkapi tabel penelusuran fase dan
        jelaskan satu keputusan desain.
  \item Tentukan tipe ekspresi campuran dan jelaskan promosi.
  \item Diberikan AST, tuliskan aturan validasi yang dilanggar.
  \item Rancang pesan kesalahan untuk tiga kasus berbeda.
  \item Usulkan perbaikan desain untuk program yang gagal validasi.
\end{enumerate}
