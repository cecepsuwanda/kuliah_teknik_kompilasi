\section*{Checklist Pencapaian Kompetensi}
\addcontentsline{toc}{section}{Checklist Pencapaian Kompetensi}

\begin{checklist}
  \item Saya dapat membuat AST.
  \item Saya dapat melakukan traversal AST.
  \item Saya dapat menerapkan aturan validasi secara multi-pass.
  \item Saya dapat mengklasifikasikan kesalahan.
  \item Saya dapat memulihkan dan melanjutkan analisis.
  \item Saya dapat menguji pesan kesalahan sintaksis yang informatif.
  \item Saya dapat men-\textit{debug} kesalahan semantik.
  \item Saya dapat menghasilkan diagnostik yang menyebut baris, nama,
        dan jenis pelanggaran.
  \item Saya dapat menguji program valid dan tidak valid.
  \item Saya sudah menyelesaikan M5/Proyek Akhir.
\end{checklist}
